HUD 风格四选一

下面四块是 完全相同的界面内容（同一个品牌头、同样 4 个 Agent、同样任务图、同样状态条）， 只换视觉语言。挑一个你最顺眼的编号就行。

说明：状态一律用「色块」而不是「彩色文字」——除非底色够深（只有方案 C 满足）。

自检：背景模糊滤镜 0 处 · 圆角最大 2px · 四块内容同源
方案 A · 推荐 像素纸 / 木质面板 Stardew Valley · 牧场物语 · 我们自己的 9-slice

米色纸面板 #D3BF8F + 2px 双层描边（外亮 #D9CDAF / 内暗 #B1A077）+ 3px 3px 0 硬阴影 + 0 圆角。 色值全部从游戏素材 Ancient/tan.png 采样，和场景里的对话气泡是同一套材质。

什么时候选它 → 想让面板看起来「长在游戏里」、和像素小人同一世界时。 代价：米色纸很亮，和深色场景对比强，这是它的风格特征（不是缺陷）。

方案 B 复古蓝窗 Final Fantasy · Dragon Quest 系列

深蓝底 #1B2A6B + 白色 2px 双层边框 + 2px 极小圆角 + 大内留白。 一眼就认出是「RPG 菜单」，白色外框是这一派最标志性的特征。

什么时候选它 → 想要最强烈的「这是游戏」的第一印象、且能接受信息密度偏低时。 代价：白框很抢眼，数据一多会显得"框套框"。

方案 C 现代扁平深色 RimWorld · Prison Architect 等模拟经营

深灰不透明 #22252B + 1px 细线 + 无阴影无圆角，最像"工具"。 注意：这四块都按你的要求保持了宽松留白，所以 C 只是"最有条件做紧凑"的语言，这里并没有做成紧凑版。 ⚠️ 本方案用亮色文字表状态（深灰上实测 ≥4.9:1 可读）——这条只在深底成立，换浅底必须改回色块。

什么时候选它 → 更看重「看数据、操作快」而不是"游戏感"时。 代价：和像素办公室场景最不像，可能仍然是"网页贴在游戏上"。

方案 D 终端 / CRT 赛博朋克 · 系统监控台

近黑底 #0A0E0A + 荧光青绿 #4FE3C1 + 等宽字 + 极淡扫描线。 最像"监控室大屏"，和「盯着团队状态」的定位非常贴。

什么时候选它 → 想强调「这是监控台」、追求赛博感的氛围时。 代价：和明亮的办公室场景最容易割裂；长时间盯荧光色眼睛会累。

怎么选：一句话对照

方案第一印象和像素场景的协调度信息密度一句话
A · 像素纸「这是游戏」最高（同一套素材）中最推荐：面板像游戏的一部分
B · 复古蓝窗「这是 RPG」高偏低游戏感最强，但框太抢眼
C · 扁平深色「这是工具」最低高（可做最紧凑，本页未做）最好用，但最不像游戏
D · 终端 CRT「这是监控台」中中氛围独特，但容易和场景割裂

也可以混合：例如 A 的面板 + C 的状态色块（用纸面板，但状态块更克制）。 告诉我要哪个编号（或怎么混），我再去做实现。
