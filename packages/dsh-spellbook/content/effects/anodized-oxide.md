## 描述

一块蓝紫色金属，沿着一个方向颜色连续滑过蓝、紫、品红、再回到蓝，中间没有断层。

机制是 ==把色相按等步长铺成一圈，每一步都小于 180 度==。阳极氧化的颜色来自氧化膜厚度——膜厚随曲面位置连续变化，颜色就随位置连续变化。而色相是个环，插值时有两条路可走，默认规则是**走短弧**：给两个相差 30 度的色标，它当然向前走；但如果写成首尾同色的一圈，终点与起点色相相同，短弧长度为零，色相就会在原点附近来回而不前进。所以序列必须显式地一小步一小步写满一圈（示例里每步 30 度），短弧规则才会老老实实一路向前。

用 `oklch` 而不是默认的 sRGB 也是必要的：在 sRGB 里插值，蓝到紫的中途会穿过一段发暗的灰（因为它是在 RGB 坐标里走直线，不沿着色相走），oklch 的插值作用在感知均匀的空间里，中途的明度不会塌陷。

```css
.ao {
  width: 280px;
  height: 200px;
  border-radius: 50%;
  /* @mechanism 色相每步 30 度、逐步铺满一圈：步长都在 180 度内，短弧才会一直向前 */
  background: conic-gradient(
    from var(--from, 200deg) in oklch,
    oklch(56% 0.17 250),
    oklch(58% 0.16 280),
    oklch(54% 0.19 310),
    oklch(56% 0.18 340),
    oklch(60% 0.16 10),
    oklch(64% 0.15 40),
    oklch(66% 0.14 70),
    oklch(62% 0.15 100),
    oklch(56% 0.17 250)
  );
  /* @mechanism 明暗与色相分开处理：色相管膜厚，这层斜向明暗管表面朝向 */
  box-shadow:
    inset 10px 12px 30px rgb(255 255 255 / 0.2),
    inset -14px -16px 34px rgb(0 0 0 / 0.5),
    0 12px 30px rgb(0 0 0 / 0.5);
}

.ao::after {
  content: "";
  display: block;
  height: 100%;
  border-radius: inherit;
  /* @mechanism 一道窄的柔光，把「氧化膜」拉回「金属上的氧化膜」 */
  background: radial-gradient(30% 40% at 32% 24%, rgb(255 255 255 / 0.6), transparent 62%);
  mix-blend-mode: screen;
  pointer-events: none;
}
```

## 边界

- **首尾必须同色（或同角度）。**第二个色标与最后一个色标不同色时，锥形渐变会在 12 点方向留下一道硬边——那是渐变的起点接缝，会醒目地立在那里。示例首尾都写 250，接缝才消失。
- 步长一旦超过 180 度，短弧规则会**掉头往回走**，色相在中途折返，颜色出现折痕。所以「色相铺满一圈」必须靠多写几个中间色标，不能靠两三个大跨度色标。这也是 `longer hue` 那类关键字容易踩的坑：它把每一段都改成绕远路，相邻的近色标会各自兜一整圈，结果是一圈里绕好几轮、来回穿插，而不是单调扫过。
- `in oklch` 的插值写法较新，旧引擎不支持时**整条渐变会失效**（回退成透明），而不是退化成 sRGB 插值。属性值解析失败是静默的，页面上只表现为「那块颜色没了」。
- 它是锥形渐变，色相绕**中心**分布。放在圆上正好；放在长方形上，渐变的中心会暴露出来，四角的色相明显不是一路走过去的，像贴了张图。长方形场合要改回线性渐变或另加一层色相位移。
- 明暗与色相必须分两层。这条渐变里只放色相，明暗全靠 `box-shadow` 的 inset——把明暗也塞进色标会与 inset 打架，金属感变成塑料感。
- 它和 `iridescent` 的分界：那个是色相在角度上**分段跳变**（几段相邻色相接），像珠光漆；这个是色相**连续单调**地推进，像氧化膜。
- 完全静态。真阳极氧化件转动时色带会整体平移，这里只有 `from` 可调；动起来要注册 `@property` 后做过渡，代价是每帧重绘整层渐变。

## 备注

- 把序列换成首尾同明度、只改色相，就得到一条标准色轮，适合做取色控件。
- `in oklch` 也适用于线性渐变：同样两个端点，在 sRGB 里插值会穿过灰，在 oklch 里保持饱和度——这是给渐变「提纯」的通用手段。
