## 描述

一圈从中心射出的扇形，条数由角度决定，一个元素就够了。

机制是 ==repeating-conic-gradient 的色标按角度循环，一圈里会重复 360° 除以角距那么多次==。锥形渐变的色标位置是角度，不是距离，所以「重复」这件事对它是天然的：把一对硬色标（一段有色、一段透明）写在 0° 到 15° 之间，整圈就自动出现 24 条等角扇形。改角距就是改条数，不用重画，也不用写 24 条色标。

圆心那一块是把扇形「灭掉」的关键。它在中心是发散的：同一条扇形靠圆心只有几个像素宽、靠外沿十几像素宽，所以直接铺满会像一团糊住的线。这里用一层不透明的径向渐变盖住圆心（不是 `mask`），让它从中心淡出——但这也意味着它只能盖在纯色底上，因为它盖的是「画」，不是「透明」。要在有内容的元素上做同样的淡出，得换成真正的 `mask`。

## 代码

```html
<!-- @mechanism 一个空盒：扇形与圆心那层都是背景，元素里什么都不用放 -->
<div class="fan"></div>
```

```css
.fan {
  width: min(280px, 74vw);
  aspect-ratio: 1;
  border-radius: 50%;
  background-color: #0d0a14;
  /* @mechanism 列表里第一层在最上面：一块不透明的圆把扇形从圆心糊掉，这是「画」而不是遮罩 */
  /* @mechanism 第二层：一对硬色标写在 0 到角距之间，整圈按角度重复 360° / 角距 次 */
  background-image:
    radial-gradient(circle at 50% 50%, #0d0a14 0 30%, rgb(13 10 20 / 0) 56%),
    repeating-conic-gradient(
      from 0deg at 50% 50%,
      #d9a441 0 calc(var(--spoke, 15deg) / 2),
      rgb(217 164 65 / 0) calc(var(--spoke, 15deg) / 2) var(--spoke, 15deg)
    );
}
```

## 边界

- 扇形的宽度随半径线性增长。同一角度在圆心附近不足 1 设备像素、在外沿十几像素，所以扇形天然是尖楔，靠角度做不出等宽的放射带——要等宽得用 `mask` 或线性渐变拼。
- 上层那块圆的颜色就是底色。底色不是纯色（渐变、图像、半透明）时，它会在中心留下一个明显的实心圆斑，这时必须换成 `mask`。
- 条数超过约 40 条后就数不清了，整块糊成一圈灰。要细密的放射线，得放大元素、或者接受它就是「光晕」而不是「扇形」。
- 硬色标的边界落在非整数像素上时会出灰边；圆心附近所有扇形的边界挤在一起，那圈灰边最明显，看起来像中心有个污点——这通常得靠上层那块圆盖住。
- `border-radius: 50%` 只裁外轮廓，扇形在外沿被裁成圆弧。元素是长方的时候，扇形会被拉成椭圆分布（锥形渐变的角度在非方形下仍然按方位算，所以看起来是「被压扁的光」）。

## 备注

- 让透明那一端不用纯透明而用同一个颜色的低 alpha，扇形之间会有柔和的过渡，像光的散射；两者视觉差别很大，值得都试试。
- 同样的结构换成 `conic-gradient`（不重复）并给若干个不同的硬色标，就是饼图或色轮。
- 把 `from` 的角度做动画，整圈扇形会缓慢旋转；因为它绕圆心循环，动画的终点等于起点，天然无缝。
