## 描述

一层扇贝纹：半圆一片压一片，排成一片一片的鳞。

机制是 ==每块瓦片在自己的顶边中点挂一个半径等于半格宽的半圆，第二层整体错开半格==。第一层的半圆一行行并排、互不相交，空隙正好是「下半格」；第二层错半格之后，它的半圆刚好落进这些空隙里，两层拼起来不重不漏——这就是平面镶嵌，而不是靠叠放。定位用 `at 50% 0` 而不是 `at 50% 100%`，是为了让第一排从元素顶边开始，否则顶部会空出半格。

半径给的是显式长度 `circle <长度> at <位置>`，所以它跟瓦片尺寸是两个独立的数：把半径调得比半格大，鳞片就会互相压住，出现真正的叠瓦；调小就变成点点之间的留白。这两种读法（镶嵌 vs 叠压）只差这一个数，这是这类图案最值得试的旋钮。

## 代码

```html
<!-- @mechanism 鳞片是两层背景瓦片，盒子内是空的 -->
<div class="scales"></div>
```

```css
.scales {
  width: min(320px, 78vw);
  height: 170px;
  background-color: #0d0a14;
  /* @mechanism 圆心在顶边中点、半径 = 半格宽：每个图块里正好装一个半圆 */
  background-image:
    radial-gradient(
      circle calc(var(--cell, 34px) / 2) at 50% 0,
      #b4462f 0 86%,
      #d9a441 86% 100%,
      rgb(13 10 20 / 0) 100%
    ),
    radial-gradient(
      circle calc(var(--cell, 34px) / 2) at 50% 0,
      #6d2a1c 0 86%,
      #8f6b2c 86% 100%,
      rgb(13 10 20 / 0) 100%
    );
  background-size: var(--cell, 34px) var(--cell, 34px);
  /* @mechanism 第二层在 x、y 各错半格，正好补上第一层半圆之间的空隙 */
  background-position: 0 0, calc(var(--cell, 34px) / 2) calc(var(--cell, 34px) / 2);
}
```

## 边界

- 半径必须正好是格宽的一半，两层的行距才是半格。半径取小了，两排之间横着一条缝；取大了，第二层会被第一层盖住一部分，镶嵌变成叠压——观感完全不同，得自己选。
- 显式半径之外的部分是透明的，所以渐变的色标列表必须以一个全透明色收尾。忘了这一条，`circle 17px` 外面的整片区域会被最后一个颜色填满，整块变成纯色。
- 圆的尺寸只能是一个长度，不能写百分比（`circle 50%` 是无效语法）。想要「随瓦片缩放」的圆，只能不写尺寸、靠默认的 `farthest-corner` 算，然后接受半径随瓦片变化。
- 两个方向的错位必须都是半格。只错 x 不错 y，第二层的半圆会和第一层同行，看起来是「一行一行的扇贝」而不是鳞。
- 半圆的外沿是圆弧，在半径只有十几个像素时，86%–100% 那圈「边」只有 1–2 像素，很容易被抗锯齿吃掉，鳞片看起来是平涂的。

## 备注

- 把圆心从 `at 50% 0` 换成 `at 50% 100%`（圆口朝上），就得到向上翻的一层，两层交替能做出「瓦片 + 阴影」的屋面。
- 半径略大于半格时，鳞片互相压住，此时两层的颜色顺序（谁写在前面）才真正决定谁压住谁。
