# 给存量咒语重打标签 —— 派工书

工作目录：`/Users/kp/DEV/dsh-plugins/packages/dsh-spellbook`

## 背景（一句话）

咒语书原先的标签是随手写的关键词：332 条咒语挂着 **631 个不同标签**，其中 458 个只出现过一次，
「吸附」与「滚动吸附」并排、「SVG 滤镜」与「SVG滤镜」只差一个空格。这种标签筛不了也数不出。
现在有了一份**受控词表**，你要做的就是把分配给你的那批文件按词表重新打标签。

## 第一步：先看词表（必做）

```bash
node scripts/tags.mjs
```

会打印四个轴和每个轴允许的值（共 189 个）。**只能从这些值里挑**，写别的校验直接拒绝。

四个轴：

| 轴 | 问的是 | 例 |
|---|---|---|
| 机制 `mech` | 靠什么做出来的（平台能力） | `backdrop-filter`、`mask`、`subgrid`、`grid`、`keyframes` |
| 观感 `look` | 看起来像什么 | `玻璃`、`金属`、`发光`、`颗粒`、`图案` |
| 场合 `use` | 用在哪 | `表单`、`卡片`、`导航`、`加载`、`标题` |
| 触发 `how` | 什么让它动起来 | `悬停`、`滚动`、`拖拽`、`焦点`、`入场` |

## 第二步：拿到你负责的文件

```bash
node scripts/batch.mjs <你的编号> 10      # 例如 3
```

它会打印一串 `content/effects/xxx.md`，**那就是你的全部范围**。别的编号的文件不要碰。

## 第三步：逐条重打标签

对每个文件：读它的 `title` / `when` / `## 描述`（尤其那句 `==机制==`），然后**只改 `tags:` 这一行**。

规则（校验会逐条查）：

1. **3–6 个标签**，全部取自词表，不许重复。
2. **至少 1 个 `mech`** —— 每条咒语都得说得清靠什么成立。
3. **至少 1 个 `use` 或 `look`** —— 只说机制不说用途，等于没说这条是干什么的。
4. 其余按需。一条最多 6 个，塞满了每个都变噪声。

怎么挑：

- **机制要挑具体的那个属性，不要挑笼统的家族。** 用 `backdrop-filter` 做磨砂的就写
  `backdrop-filter`，不要写 `filter`；用 SVG 滤镜的写 `svg-filter` 再加具体那个
  （`feTurbulence` / `feMorphology` …）。
- **不要翻译旧标签，要重新判断。** 旧标签里有价值的词（比如「表单」）可以留，但
  一定要问自己：一个想找这条咒语的人，会在哪个轴上找它？
- **`look` 只在真的是一种观感/材质时给。** 一条讲 `text-wrap: balance` 的排版咒语
  不该有 `look`，它该有 `use`（比如 `标题`）。
- **`how` 只在真的有个触发源时给。** 一条静态材质没有 `how`，这是正常的。
- 拿不准某个概念该用哪个值时，不要自己造词 —— 从词表里挑最接近的。

## 第四步：自检（必做，且只查你自己的文件）

```bash
node scripts/check-file.mjs content/effects/a.md content/effects/b.md ...   # 你那批
```

必须看到每个文件都是 `✔`，末行是 `<N> 通过 / 0 有问题`，退出码 0。
报错会告诉你哪个标签不在词表里、哪条缺轴——照着改，改完再跑一次。

> 注意：**别的批次的文件此刻大概率还是红的**（还没轮到它们改）。
> 所以只查你自己的文件，不要跑 `content/effects/*.md`，那会看到一堆不归你管的错误。

## 纪律

- **只改 `tags:` 那一行。** 标题、描述、代码、边界、其他 frontmatter 字段一律不要动。
- 不要新建文件，不要删文件。
- 不要跑 `build.mjs` / `scripts/vault.mjs` / `git`。
- 不要开浏览器、不要截图、不要写临时脚本。
- 不要往 `shared/tags.mjs` 里加值（要加也是我来加）。缺值就挑最接近的现成值。

## 回报

用尽量短的形式：`第 k 份，N 个文件全部重打，check-file 输出：N 通过 / 0 有问题（exit 0）`，
外加**你拿不准或有疑问的条目**（有才写）。不要复述词表，不要贴文件全文。
