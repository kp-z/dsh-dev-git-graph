# Insight 卡片设计（早会视图）

> 对应任务：`📊 T12-Insight 卡片：早会式任务诊断与推荐`
> 目标：把「早会」要问的三件事一屏给全 —— 昨天做了什么、今天该做什么、哪里卡住了。

## 1. 位置与形态

放在任务列表**上面**、和「筛选」同一区块，默认收起成 3 行：

```
┌───────────────────────────────────────────────┐
│ 🤖 今日洞察          9 完成 · 3 在推 · 2 卡住  ⟳ │
│ 🩺 T12 三轮没提交记录；T9 卡在联调；T2 还没开工   │
│ [昨天做了什么]  [今天做哪些]  [导出早会摘要]      │
└───────────────────────────────────────────────┘
```

- 第一行：AI 小人 + 今日数字（纯本地，秒出）
- 第二行：一句话诊断（点开看 3 条，带证据）
- 第三行：三个动作
- 展开后分三块：`诊断` / `数据评估` / `回顾与推荐`

## 2. 三块内容

### 2.1 AI 诊断（按需调用模型）

输入：

| 输入 | 取多少 |
| --- | --- |
| 任务 | 编号 / 标题 / 状态 / 工作区 / 最后活动时间 / 评论数 |
| 会话 | 每条任务最近 N 轮的**助手文本首段**（各 ≤ 200 字）+ 工具调用名序列 |
| 产出 | 文档数、提交次数（从进展评论里统计） |

输出结构（固定 JSON，便于渲染）：

```json
{"headline":"今天主要在推插件，但两条任务停在验证环节",
 "issues":[{"taskNo":12,"level":"warn","text":"三轮没有提交记录","evidence":"最近 3 轮只有本地编辑"}],
 "score":{"focus":72,"throughput":60,"hygiene":80},
 "advice":"先把 T12 的跳转问题收口，再开新活"}
```

缓存键：`日期 + sha1(任务 id/title/done/最后活动)`；同一天同一状态不重复调用。

### 2.2 本地数据评估（不花 token，打开就有）

| 指标 | 口径 |
| --- | --- |
| 今日活跃 | 今天有会话轮次或进展评论的任务数 |
| 完成 / 开工 / 新增 | 按 `completedAt` / `startedAt` / `firstSeenAt` 落在今天 |
| 完成度 | 今日完成 ÷ 今日活跃 |
| 停滞 | 开工后 ≥ 2 天没有进展评论、没有文档更新 |
| 偏离度 | 任务标题关键词与「会话最近内容」的重合率 < 阈值 → 标「可能跑偏」 |
| 产出 | 今日文档数、提交次数（正则 `git commit` / `[0-9a-f]{7}`） |

偏离度是启发式的，先给粗判（高/中/低三档），不做精确打分。

### 2.3 回顾与推荐

- **昨天做了什么**：昨天完成的任务（含完成时间）+ 昨天有进展但没完成的（附最后一条进展摘要）
- **今天做哪些**：排序规则
  1. 昨天没做完的（延续性）
  2. 触发条件=自动且未开工的
  3. 停滞最久但工作区最近活跃的
  4. 编号小的（老任务优先收尾）
  每条给一句「为什么推荐你」。

## 3. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/insight?day=today` | 本地指标 + 回顾 + 推荐（纯计算，无模型） |
| POST | `/api/insight/diagnose` | AI 诊断（带缓存，可强制刷新） |
| POST | `/api/insight/export` | 把上面的内容写成一条飞书评论 / 一篇文档 |

## 4. 成本与隐私

- 一次诊断控制在 **4k token / 15 条任务**以内，摘要各截 200 字。
- 只发任务标题、状态、摘要首段；**不发代码、不发完整对话、不发文件路径细节**。
- 默认**不自动调用**：打开面板只算本地指标，点 🤖 才诊断。

## 5. 降级

| 情况 | 表现 |
| --- | --- |
| 没有模型 / 超时 | 显示本地规则诊断（停滞项、无产出项），并标注「AI 不可用」 |
| 任务为空 | 空态：「今天还没有可评估的任务」 |
| 会话读不到 | 只用任务自身状态算指标 |

## 6. 分期

| 期 | 内容 | 预估 |
| --- | --- | --- |
| P1 | 本地指标 + 昨日回顾 + 今日推荐（纯计算，无模型） | 1 天 |
| P2 | AI 诊断（缓存 + 降级 + 展开看 3 条） | 1 天 |
| P3 | 导出为飞书评论/文档，接进「早会」流程 | 半天 |
