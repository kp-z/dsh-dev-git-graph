## 描述

一片米白的表面，浮着几团极其柔和的淡粉、淡青、淡金，看不到任何硬边。

机制是 ==多层错位的径向渐变，每一层的对比都压到极低，并且周期互不整除==。珍珠的光泽和金属、虹彩都是邻家但不同根：金属靠同一色相的明暗高频跳变，虹彩靠色相沿角度连续旋转，而珠光靠的是**大片区域在极小色差里缓慢漂移**。单层渐变做不到这一点——一层的过渡是单调的，看久了就是一个色斑。把四五团不同色相、不同位置、尺寸互不成整数倍的光斑叠起来，各处的混色比例都不同，于是任意截一块看都能看到细微的偏移，这才有「各方向都在微微反光」的珠层感。

「周期互不整除」是这套机制的技术核心。如果几团光斑的半径或位置是简单倍数关系，它们会在某些位置同时达到极值，形成肉眼可辨的对称纹样（像曼陀罗），珠光的随机感立刻消失。示例里的位置和尺寸刻意取了一组没有公约数的值。

对比度必须极低。这里所有色标都是 RGB 三通道同时很高的浅色，彼此差值只有十几个数值单位；把任何一个换成高饱和色，珍珠就变成塑料珠。

```css
.pl {

    inset 0 1px 0 rgb(255 255 255 / 0.8),
    inset 0 -2px 8px rgb(120 110 100 / 0.18);
}

.pl::after {
  content: "";
  display: block;
  height: 100%;
  /* @mechanism 一道窄而柔的高光压在最上层，给出「有厚度」的珠层反光 */
  background: radial-gradient(28% 42% at 34% 18%, rgb(255 255 255 / 0.85), transparent 66%);
  mix-blend-mode: soft-light;
  pointer-events: none;
}
```

## 边界

- **色差必须小。**所有色标的明度都要在浅色区，单通道差值控制在 20 以内。任一色斑换成饱和色，珍珠立刻变成糖豆——珠光的全部信息就藏在这点色差里。
- 周期不能成整数倍。两团光斑半径比是 1:2、位置在对称轴上时，叠加处会出现明显的对称花瓣，随机感崩塌。这是最容易忽略又最致命的失败方式。
- 白底上几乎看不出效果：珠光是浅色对浅色，需要一个中性或偏冷的底才成立。`stage` 是 `photo` 就是为此——它需要一点环境色才显形。
- `mix-blend-mode: soft-light` 那一层如果去掉，剩下的是「磨砂纸上的彩斑」，缺少珠层内反光的那道窄高光。但 `soft-light` 在很浅的底上作用甚微，底如果调得很亮，这层等于不存在。
- 它完全不适合做交互高光。珠光没有明确的光源位置，跟鼠标走会显得很怪——这是它和 `specular-highlight` 的根本区别。
- 层数不是越多越好。超过六层之后每层的贡献被稀释到看不见，反而拖慢合成。五层左右是收益拐点。

## 备注

- 同一套叠法换成偏冷的青紫系就得到「极光」「珍珠贝母」；换成偏暖的金橙就是「香槟金箔」的柔光版。
- 想让它在滚动或倾斜时缓慢漂移，可以给每层的 `at` 位置加不同的过渡时长——因为是背景，动画开销比变换整块元素低。
