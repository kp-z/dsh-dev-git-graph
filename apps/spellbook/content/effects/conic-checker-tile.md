## 描述

一片棋盘格，两种颜色，格子大小随一个值走——没有图片，也没有第二条渐变。

机制是 ==把一整圈切成四个 90° 扇区、两色交替，一个圆盘本身就是一张 2×2 的棋盘图块==。锥形渐变的方向只由角度决定：0°–25° 是右上、25°–50° 是右下、50°–75° 是左下、75°–100° 是左上，对角同色时这四块拼起来正好是棋盘。剩下的复制工作交给 `background-size`——它同时定了平铺的步长，也定义了格子的边长（可见方格是它的一半）。

这里的关键是「一个图块里已经装着一个完整的周期」。两条斜线交叉也能得到格纹，但那是两组条纹的干涉，读起来是斜的；锥形渐变画的是四个象限，边界落在正上正下正左正右，所以格子是方的。想让格子随容器缩放，把 `background-size` 换成百分比或 `cqmin` 就行，色标一个也不用动。

## 代码

```html
<!-- @mechanism 棋盘全在背景层上，盒子里不需要任何内容 -->
<div class="ckt"></div>
```

```css
.ckt {
  width: min(300px, 78vw);
  height: 170px;
  /* @mechanism 四个 90° 扇区两色交替，一个圆盘就是一张 2×2 棋盘图块 */
  background-image: conic-gradient(
    #d9a441 0 25%,
    #241c33 0 50%,
    #d9a441 0 75%,
    #241c33 0
  );
  /* @mechanism 图块边长 = 两个格子；复制由 background-size 负责，不用 repeating */
  background-size: var(--cell, 26px) var(--cell, 26px);
  border: 1px solid rgb(217 164 65 / 0.2);
}
```

## 边界

- 图块是 `background-size` 给的那个矩形。给它一个长方形的值，出来的是交错的砖墙，不再是方格——「方」这个性质来自宽高相等，不来自渐变。
- 对角同色是必须的。四个扇区各用一个颜色时，每个图块是四色瓦，平铺后每个格子都在重复同样的四色排布，看起来是万花筒而不是棋盘。
- 扇区的分界落在图块的两条中线上。`background-size` 取奇数像素时中线落在半个设备像素上，格子的边被抗锯齿摊成一条灰线，棋盘看着有点脏。
- 它只能做**实心**格子，没有「线宽」这个量。想要描边式的格线（细线网格）得用线性渐变加 `background-size`，那条路里线宽才是独立的旋钮。
- 元素被 `transform: scale` 缩放时图块跟着缩放，非整数倍率下格子边会糊；要清晰就得改 `background-size` 而不是缩放元素。

## 备注

- 把 0°–75° 那三处色标换成三个不同颜色，就得到一张「四色瓦」图块——平铺后是另一种图案（每块都在重复同样的四色），可以当瓷砖拼花用。
- 同样的结构换成 `repeating-conic-gradient`，扇形会在一条渐变内部自己循环，完全不依赖平铺——那是另一种做法，适合做放射纹而不是棋盘。
