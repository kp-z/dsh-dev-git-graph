## 描述

一块深色卡片的四周有一圈金色细边，左上偏亮、右下偏暗，像镶了一圈金属丝。

机制是 ==`border-image` 把一张渐变按九宫格切进四条边==。常规做法是「背景渐变 + 内层遮住中间」或「伪元素压在上面」，都要多一层元素。`border-image` 不需要：它把渐变源图按 `border-image-slice` 切成 3×3 九块，四条边各取一块拉伸或平铺，四角各取一块。所以只要给一个斜向的**明暗渐变**，四条边就自动拿到不同的切片——左上角的切片亮、右下角的切片暗，金属丝受光的错觉直接出现，而中间那块（默认被丢掉，除非加 `fill`）不会覆盖内容。

`border-image` 默认用 `border-image-repeat: stretch`，把一个 1px 宽的切片沿整条边拉伸。拉伸的是**渐变的一小段**，所以颜色在边上几乎不变，看起来就是一根均匀的金属丝——这正是要的效果。如果改成 `repeat`，那 1px 会被反复平铺成条纹，金属丝立刻变成斑马线。

## 代码

```html
<div class="mb">
  <strong>镶边卡片</strong>
  <span>四下受光不同，像真的金属丝</span>
</div>
```

```css
.mb {
  /* @mechanism border-image 把渐变按九宫格切片：四角各取一块，四条边各取一块拉伸 */
  border: 2px solid transparent;
  border-image: linear-gradient(135deg, #ffe9a8 0%, #b98a26 22%, #4a3208 48%, #d8b45c 74%, #6d4d12 100%) 1;
  border-radius: 10px;
  padding: 22px 26px;
  background: #15120e;
  display: grid;
  gap: 6px;
  font: 400 14px/1.6 system-ui, sans-serif;
  color: #efe6d2;
}

.mb strong {
  font-size: 17px;
  font-weight: 700;
  letter-spacing: 0.02em;
}

.mb span {
  opacity: 0.7;
}
```

## 边界

- **`border-image` 与 `border-radius` 不兼容。**这是最刺眼的失效：一旦用上 `border-image`，圆角会被**忽略**，边框按直角矩形绘制（浏览器不报错，只是圆角没了）。示例里保留 `border-radius` 为了让背景那层还是圆角，但你看到的那圈金边始终是方的。要圆角金属边必须回到「背景渐变 + 内层遮盖」或伪元素方案。
- `border-image-slice: 1` 里的**数字不带单位**，它是切片在源图坐标系里的宽度。写成 `1px` 会被当作另一种含义，切出来的是完全不同的九宫格。用渐变当源图时（没有固有大小时），`1` 就等于「每边切 1 单位的渐变跨度」。
- 默认不写 `fill` 时，源图的**中间那块被丢掉**——这正是它不遮内容的原因。一旦加上 `fill`，中间那块会画在背景之上、内容之下，深色卡片会突然多出一层渐变，看着像背景失效。
- 渐变必须是**斜向**的（135deg 一类）。水平或垂直渐变沿四条边切出来会左右对称、上下对称，金属丝会读成「四条一样的边」，立体感受到损失。
- 四角各取一块源图。渐变在角上是连续的，所以角部的明暗过渡自然；但如果源图里有一个突兀的色阶正好落在角上，那个角会出现一块突兀的亮斑。
- 它不叠任何阴影与圆角，是纯粹的一根线。想要「镶进去」的金属槽，得再叠 `inset` 阴影，那已经不是 `border-image` 的职责。

## 备注

- 换成 `conic-gradient` 当源图，四条边会各自拿到不同的角度区间，得到「光在绕圈」的边框，配合旋转的 `from` 角就是流动金边。
- 同一套切片逻辑也是「九宫格纹理边框」的标准做法：源图换成一张 PNG，就能给任意尺寸的盒子套上带装饰角的框。
