## 描述

细密的条纹上浮出一层大得多的横向暗带，而这层大图案并不是画上去的。

机制是 ==两层条纹的周期只差几个百分点，差值就是「拍」，拍长等于两周期之积除以周期差==。周期 6px 与 6.36px 的两层条纹，同相位的地方两层都盖住底色、反相位的地方有一半的缝露出来，于是整体浓淡以 106px 为周期起伏——这层大图案的尺度比两个源周期都大一个数量级，所以它看起来完全是另一个东西。周期差是唯一的方向盘：差别越小，拍越长。

拍只改变「这一片区域的整体浓淡」，不会给出新的颜色。两层的 alpha 在那里叠加得更满，蓝底上看起来就像一块被压暗的横向条带，条纹本身仍然在。想让拍更凶，把其中一层换成对比更强的颜色或用 `screen`、`multiply` 混合，而不是把 alpha 调高——那只会让条纹先糊掉。

## 代码

```html
<!-- @mechanism 只有两层背景，没有任何一层是那层大图案 -->
<div class="mb"></div>
```

```css
.mb {
  width: min(320px, 78vw);
  height: 170px;
  background-color: #0d0a14;
  /* @mechanism 一层用周期本身，另一层用周期的 1.06 倍，拍长 = p×1.06p / 0.06p */
  background-image:
    repeating-linear-gradient(
      0deg,
      rgb(217 164 65 / 0.55) 0 calc(var(--pitch, 6px) / 2),
      rgb(13 10 20 / 0) calc(var(--pitch, 6px) / 2) var(--pitch, 6px)
    ),
    repeating-linear-gradient(
      0deg,
      rgb(217 164 65 / 0.55) 0 calc(var(--pitch, 6px) * 0.53),
      rgb(13 10 20 / 0) calc(var(--pitch, 6px) * 0.53) calc(var(--pitch, 6px) * 1.06)
    );
}
```

## 边界

- 周期差越小拍越长。差到拍长超过元素高度时，整块看起来只是「上暗下亮」，图案感消失——这是最容易调过头的一处。
- 两个周期成整数倍关系时拍**消失**：这时两层花纹互相嵌套、整体有严格周期，画面变得规整安静（那是「谐波格」那种效果，不是摩尔纹）。
- 别把这类干涉纹和「图案与屏幕像素栅格打架」出来的摩尔纹混为一谈。后者在 `transform: scale`、子像素滚动、缩放页面时出现一片随位置移动的亮暗带，位置由设备像素决定，你控制不了；这里说的是图案自己叠出来的。
- `calc()` 算出的小数 px 会被设备像素量化：1× 屏幕上的 6.36px 实际落在 6 或 6.5 个设备像素之间，拍的位置因此会随窗口宽度、DPR 变化而漂移。
- 两层用同一个颜色时，拍只体现为不透明度的起伏。换成两个互补色能让拍读起来像「另一层图案」，但也会让细条纹变脏——细条纹本身已经接近分辨率极限了。

## 备注

- 同样的配方把两层换成两组同心环（`repeating-radial-gradient`），就能得到一圈圈缓慢游动的网状亮纹；换成两组点阵，则出现放大的蜂窝状块。
- 想让它慢慢动，把其中一层的 `background-position` 用很长的周期平移即可，拍会跟着缓缓扫过。
