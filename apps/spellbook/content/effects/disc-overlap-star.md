## 描述

一片圆盘交叠的底纹，圆与圆之间空出来的地方是一颗四角星。

机制是 ==四个圆心分别放在瓦片的四个角上，于是每个格点上的整圆是相邻四块瓦片各出一个象限拼出来的；半径一旦超过半格，相邻圆盘就相交，剩下的负空间正好是一颗四角星==。关键在半径落点：小于半格时相邻圆不相交，只是一片普通点阵；超过半对角时连格子中心都被盖住，整块变成实心。可行的区间是「半格」到「半对角」之间——以瓦片对角线为 100%（默认的 `farthest-corner`）换算，就是 35.4% 到 50%。这条咒语的全部可玩空间就在这两个阈值之间，而它们只由半径一个数决定。

这四个象限的拼法也是必要的：只写 `circle at 0 0` 一层时，每个格点上只有一个朝右下方的四分之一圆，读起来是「扇形阵列」而不是圆。四层让每个格点凑出完整的圆，交叠处没有接缝——因为四层是不透明的同一色，叠起来就是一块圆盘。

## 代码

```html
<!-- @mechanism 四角星不是画出来的，是四层圆盘盖不住的地方，盒子里不需要内容 -->
<div class="star"></div>
```

```css
.star {
  width: min(320px, 78vw);
  height: 168px;
  background-color: #0d0a14;
  /* @mechanism 四层各把圆心钉在瓦片的一个角上，格点上的整圆由相邻四块瓦片各出一瓣 */
  background-image:
    radial-gradient(circle at 0 0, #d9a441 0 44%, rgb(13 10 20 / 0) 44%),
    radial-gradient(circle at 100% 0, #d9a441 0 44%, rgb(13 10 20 / 0) 44%),
    radial-gradient(circle at 0 100%, #d9a441 0 44%, rgb(13 10 20 / 0) 44%),
    radial-gradient(circle at 100% 100%, #d9a441 0 44%, rgb(13 10 20 / 0) 44%);
  /* @mechanism 44% 落在半格与半对角之间，圆才既相交、又留得下中心的星 */
  background-size: var(--cell, 44px) var(--cell, 44px);
}
```

## 边界

- 半径必须落在「半格」与「半对角」之间（按对角线换算成百分比是 35.4%–50%）。低于下限圆不相交，只得到点阵；高于上限格子中心也被盖住，整块变实心，星形消失。上下都要试一下才找得到边界在哪。
- 百分比在这里是**色标位置**，圆的半径本身由默认的 `farthest-corner` 算出来。瓦片一变大，同一个百分比给出的圆跟着变大。要锁死绝对半径就写 `circle 26px at 0 0`——圆的尺寸只能是一个长度，写不了百分比。
- 星形是负空间，由底色透出来。底色与圆盘的明度接近时，星形直接消失；元素再来一层内容，星也会被盖掉。所以它只适合做纯装饰的底层。
- 圆盘间距很小（小于约 6px）时，负空间落到亚像素尺度，抗锯齿会把它糊成一层灰，整块看起来只是「有点脏的底色」。
- 瓦片是正方形才能保证四个方向对称。给成长方形时，圆仍在格点上，但格点之间的距离不等，星形会被压扁成四瓣的梭形。

## 备注

- 半径取到接近上限时四角星会胖成四瓣花；取到接近下限时星形细长如十字。想让星有「描边」，就在圆盘色标里留一圈浅色环。
- 同样的四层结构换成 `circle at 0 0` 只留一层，就是「角纹」——每个格点上朝同一方向的四分之一圆，用在四角装饰、窗花上是另一种味道。
