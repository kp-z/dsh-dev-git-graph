## 描述

一层斜着的网格，格子是菱形，只用两条线性渐变。

机制是 ==两条 ±45° 的细线各自穿过图块中心，平铺后各自展开成一族等距平行线，两族交叉就是菱形==。关键在于那条线必须落在图块的**对角线**上：45° 的线穿过方形图块的中心时正好是它的一条对角线，相邻图块的线因此首尾相接，缝隙处不断线。线的粗细由色标之间的跨度决定（46% 到 54% 就是轴长的 8%），网格的疏密由 `background-size` 决定——两者互不干扰。

这跟正交网格的差别不只是「转了 45°」。正交网格的两条线各由一个方向负责，改一条不影响另一条；菱形网格的两条线是对称的，改任何一个参数都得两条一起改，否则菱形会歪成平行四边形。把同样两条渐变的角度换成 30° 与 −30°，再把图块的宽高比调成 tan30°，也能得到规整的网格——「线走对角线」才是条件，45° 只是其中最省事的一种。

## 代码

```html
<!-- @mechanism 网格全在两条渐变里，元素本身是空盒 -->
<div class="lat"></div>
```

```css
.lat {
  width: min(320px, 78vw);
  height: 170px;
  background-color: #0d0a14;
  /* @mechanism 一条 45° 一条 −45°，围绕图块中心对称，各自是图块的一条对角线 */
  background-image:
    linear-gradient(
      45deg,
      rgb(217 164 65 / 0) 46%,
      rgb(217 164 65 / 0.85) 46% 54%,
      rgb(217 164 65 / 0) 54%
    ),
    linear-gradient(
      -45deg,
      rgb(217 164 65 / 0) 46%,
      rgb(217 164 65 / 0.85) 46% 54%,
      rgb(217 164 65 / 0) 54%
    );
  /* @mechanism 平铺步长就是菱形的对角线长度 */
  background-size: var(--cell, 32px) var(--cell, 32px);
}
```

## 边界

- 图块必须是正方形。给成长方形时，45° 的线不再是它的对角线，相邻图块的线在接缝处对不上，网格的交叉点会碎成一级级的台阶。
- 线要围绕 50% 对称。把线放到 20% 处，它就不再是对角线，同一族线在接缝两侧的相位不同，看起来像两套错开的网格叠着。
- 线宽写成百分比时，它量的是渐变轴的长度，会随图块一起变。要固定线宽就用长度：`calc(50% - 1px)` 到 `calc(50% + 1px)` 是恒定 2px 的线（色标位置接受 `<length-percentage>`）。
- 斜线在像素栅格上最容易露锯齿，尤其是 45° 这种最不利的角度；线宽不足 1 设备像素时会被抗锯齿摊成灰雾，看起来是「一块脏」而不是一条线。
- 它只有线宽和步长两个量，所以做不出「主线 + 副线」的层级。要那种效果得再叠一对周期成整数倍的渐变。

## 备注

- 把角度换成 30°/−30° 并把 `background-size` 的宽高比调成 1 : tan30°，得到的是更扁的菱形网（同样的条件：线走对角线）。
- 只要一族线（保留一条渐变），就是斜纹；两族线周期取整数倍，就变成「大菱格里套小菱格」。
