## 描述

黑暗里一盏灯的光晕，亮的地方很集中，往外衰减得很快：一离开光源就暗下去大半，然后拖出一条很长的尾巴。

机制是 ==径向渐变的色标不是均匀铺开，而是按距离平方反比挤在靠近圆心的地方==。`radial-gradient` 默认在每个色标之间做线性插值，半径每增加一点、亮度就减一点，画出来是一块边界清晰、内部平坦的圆盘。点光源不是这样：照度与距离的平方成反比，半径翻倍亮度就只剩四分之一。把这个关系翻译成色标，就是在最前面两成的半径里塞进大部分衰减（0.62 / 0.34 / 0.16），剩下的八成只负责那条很淡的长尾。

所以「看起来像光」的关键不在颜色，而在停点的位置分布。换任何色相，只要停点按幂律挤在近处，它都会立刻被读成光源；停点均匀铺开，就永远像一块渐变的装饰圆。

可变的是 `--reach`（光晕铺多大）和中心亮度。示例把停点写死成一组近似平方反比的百分比，想改衰减快慢就动这串数，而不是动颜色——颜色只决定光是什么色温，曲线才决定它像不像光。多个光源叠在一起时，每个各用自己的曲线即可。

## 代码

```html
<div class="falloff">
  <span>点光源</span>
</div>
```

```css
.falloff {
  position: relative;
  display: grid;
  place-items: center;
  width: min(420px, 86vw);
  height: 240px;
  background: #05060a;
  color: #8d8676;
  font: 400 13px/1.6 system-ui, sans-serif;
}

/* @mechanism 停点按 1/r² 挤在近处；均匀铺开就会变成一块平坦的圆饼 */
.falloff::before {
  content: "";
  position: absolute;
  left: 50%;
  top: 50%;
  translate: -50% -50%;
  width: var(--reach, 300px);
  aspect-ratio: 1;
  border-radius: 50%;
  background: radial-gradient(
    circle,
    rgb(255 244 214 / 1) 0%,
    rgb(255 232 172 / 0.62) 7%,
    rgb(255 220 132 / 0.34) 15%,
    rgb(255 206 106 / 0.16) 25%,
    rgb(255 192 84 / 0.06) 38%,
    rgb(255 180 70 / 0.015) 55%,
    rgb(255 176 64 / 0) 78%
  );
}

.falloff span {
  position: relative;
  z-index: 1;
}
```

## 边界

- 停点挤在近处，等于把渐变的有效范围压缩到很小的一段，色深不够时这里会出现同心色带——大面积光晕上要补一层噪点。
- 最后一站写的是同色相的零 alpha 而不是 `transparent`。`transparent` 在浏览器里就是 `rgb(0 0 0 / 0)`，向它插值会经过黑色，尾巴会莫名发灰；这在光晕这种大面积低透明度渐变上尤其明显。
- 平方反比在 r 趋近 0 时发散，所以圆心必然过曝成纯白。想在圆心留住颜色就得给半径设下限，而不是继续加亮度。
- 光晕画在元素自己身上，不参与场景光照，所以它不会真的照亮底下的东西。要照到内容得加混合模式，但那会连带压掉文字对比度。
- 百分比停点是相对半径的，光晕放大时衰减曲线跟着等比放大。想让它保持物理尺寸就得改用 `px` 停点。
- 一个圆只能给一个光源。多光源叠加要靠多层渐变或多个元素，且每一层都要重复一遍这串停点，参数会开始重复。

## 备注

- 同一组停点换成 `radial-gradient(ellipse ...)` 就得到椭圆光，用在俯视的灯带、桌面上很自然。
- 平方反比之外的另一种常见衰减是指数衰减（雾），它的停点分布更靠外、尾巴更长更平，两者叠起来像有雾的夜晚。
