## 描述

一块金属面板上，一道窄的白色光带斜着从左下扫到右上，扫过后表面恢复平静。

机制是 ==伪装成高光的层，其实是「窄色标渐变 + 整体平移」==。三个细节决定它像不像金属的反光：光带必须**窄**（占长度的一小部分）、扫过的方向必须与光带**垂直**、光带本身必须**几乎无色**。真金属的高光是光源直接在抛光面上的像，它的宽度由表面曲率和光源尺寸决定，通常很窄，而且因为反射不改变光谱，它几乎是白的——一旦给它染上金色或青色，就变成玻璃或塑料的反光。

方向垂直这一点最容易被做错。光带走的是横向，那它扫过去的方向就必须是纵向（或反之）。两者平行时，光带只是在原地拉长缩短，看起来像在呼吸，完全不像一道光扫过去。

`dur` 是扫过周期，不是速度。这个效果要好看，关键在于**留白**：光带扫过只占周期的一小部分时间，剩下大半时间表面是静止的。一帧不停地扫会让它像加载动画，而不是材质。

```css
.hs {
  position: relative;
  width: 300px;
  height: 180px;
  border-radius: 10px;
  overflow: hidden;
  background:
    linear-gradient(168deg, rgb(255 255 255 / 0.14), rgb(0 0 0 / 0.4)),
    repeating-linear-gradient(88deg, #767d85 0 2px, #666d75 2px 4px);
  box-shadow:
    inset 0 1px 0 rgb(255 255 255 / 0.3),
    0 10px 26px rgb(0 0 0 / 0.5);
}

.hs::after {
  content: "";
  position: absolute;
  /* @mechanism 光带做得比容器更宽，斜向平移时才不会在中途露出边缘 */
  top: -60%;
  left: -80%;
  width: 260%;
  height: 220%;
  /* @mechanism 极窄的白色色标：宽窄比决定它读作金属高光还是玻璃反光 */
  background: linear-gradient(
    76deg,
    transparent 43%,
    rgb(255 255 255 / 0.28) 46%,
    rgb(255 255 255 / 0.95) 49%,
    rgb(255 255 255 / 1) 50%,
    rgb(255 255 255 / 0.95) 51%,
    rgb(255 255 255 / 0.28) 54%,
    transparent 57%
  );
  animation: hs-sweep var(--dur, 3.4s) linear infinite;
  pointer-events: none;
}

/* @mechanism 平移方向与光带走向垂直，否则它只会在原地伸缩而不是扫过 */
@keyframes hs-sweep {
  0% {
    transform: translate3d(-22%, -16%, 0);
  }
  62%,
  100% {
    transform: translate3d(22%, 16%, 0);
  }
}
```

## 边界

- **方向和宽度是两处最容易做坏的地方。**光带走 76deg（近似竖直偏斜），平移就必须接近竖直偏斜；两者平行时只会看到光带原地伸缩。宽度上一旦拉宽成 20% 以上，它就从「高光」变成「一条白光」，金属感消失。
- 只动 `transform`，不动 `background-position`。后者每一步都要重绘整层渐变，在低端机上会明显掉帧；`transform` 走合成层，代价接近零。示例里让伪元素比容器大出许多，正是为了平移时不在边缘露空。
- 光带必须**几乎无色**。任何染色（哪怕是 5% 的暖色）都会让它读作玻璃或水面——这是它和 `liquid-glass` 那类反光的根本分工。
- 静止的底图不能是纯色。真金属没有反光时也不是平的，所以底上留了斜向明暗与细纹；底图一变纯，扫过的光带看起来就是贴上去的一张白纸。
- 周期太短会变成加载动画。光带扫过占整个周期不到四成的时间，剩下的静止才是让它读作「材质」的部分。
- 它和滚动、悬停无关，是自动循环的。想让它跟着指针位置响应，要把 `transform` 改由指针驱动——但那时它就不再是「扫过」而是「追踪高光」，语义不同。

## 备注

- 把唯一一道光带换成两三道间隔不等的窄带，就得到拉丝金属上游移的反光群。
- 同一招给文字加会变成「扫光文字」，机制不变，只是把容器换成文字的可裁切包裹层。
